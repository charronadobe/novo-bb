# cards-article-slider

Custom **cards** block. Purpose: Related-article teasers in a horizontally scrolling slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: One row per card. Cell 1: article photo. Cell 2: category tag link (paragraph), title heading, Read More link to the article (last link; makes the whole card clickable).

## Supported variations

No variations.
