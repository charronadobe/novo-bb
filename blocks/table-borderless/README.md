# table-borderless

Custom **table** block. Purpose: Compact label | value reference table such as a BMI classification list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per data row, one cell per column. No header row: the first row is data. Fill the first cell of the first row with the label and leave the first cell of following rows empty; it becomes a row header spanning those rows.

## Supported variations

No variations.
