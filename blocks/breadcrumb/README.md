# breadcrumb

Custom **breadcrumb** block. Purpose: Small breadcrumb trail at the top of article and guide pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: last row, single cell: a list (or paragraphs) of links in order; an item without a link is the current page. Optional first row: accessible name of the navigation.

## Supported variations

No variations.
