# carousel-video

Custom **carousel** block. Purpose: Single-slide video carousel with prev/next chevrons and dot indicators.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: a video link (link text = player title), optional poster image, optional caption paragraph (shown as a badge, e.g. "Generated with AI"). Optional rows "Previous | label" and "Next | label" name the arrows.

## Supported variations

No variations.
