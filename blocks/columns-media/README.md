# columns-media

Custom **columns** block. Purpose: Image or video beside heading, paragraph and CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: media (image, or a video link alone in the cell: videomarketingplatform.co .thtml, YouTube, Vimeo, Dynamic Media) | heading, text, CTA link. Cell order = desktop order.

## Supported variations

| Variation | Option class |
| --- | --- |
| Light blue panel | `light-blue` |
| Light green panel | `light-green` |
| Grey panel | `grey` |
| Stacked (media above centred text) | `stacked` |
