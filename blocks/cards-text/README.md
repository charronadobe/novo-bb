# cards-text

Custom **cards** block. Purpose: Row of rounded tinted text cards: optional icon, heading and paragraphs.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card, a single cell: optional icon image (first), heading (h3), one or more paragraphs (bold allowed).

## Supported variations

| Variation | Option class |
| --- | --- |
| Pink | `pink` |
| Light blue | `blue` |
| White (default) | `white` |
