# accordion-references

Custom **accordion** block. Purpose: Collapsible References item holding citations.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per item: title (e.g. "References:") | content (ordered list of citations).
