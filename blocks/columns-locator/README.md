# columns-locator

Custom **columns** block. Purpose: Text with a country dropdown and Find now link beside an illustration.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells. Text cell: heading, paragraph, bullet list of countries (each item a link to that country's provider finder; an optional first plain-text item is the placeholder, e.g. "Select your country"), then the Find now link. Image cell: illustration.

No variations.
