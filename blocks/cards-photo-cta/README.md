# cards-photo-cta

Custom **cards** block. Purpose: Portrait photo cards with an icon badge, short heading and a CTA button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: photo plus optional second image or :icon: for the badge; cell 2: heading or text and a CTA link.
