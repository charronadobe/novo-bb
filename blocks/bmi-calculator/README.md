# bmi-calculator

Custom **bmi-calculator** block. Purpose: Client-side BMI calculator with metric/imperial toggle, height and weight inputs, BMI result and health-risk category; nothing is submitted.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): key/value rows. Title | heading text (or a heading row); Metric | label; Imperial | label; Units label | optional legend; Height | label; Weight | label; Metric units | "cm, kg"; Imperial units | "ft, in, st, lb"; Button | button label; Result | result prefix e.g. "Your BMI is"; Error | message when inputs are missing; Category | category name | upper BMI limit (exclusive, empty for the last one) | optional description. Any other single-cell row is shown as intro text.

No variations.
