# cards-video

Custom **cards** block. Purpose: Row of video cards: poster image with a play button that loads the video inline, or the player itself when there is no poster; optional heading, quote and CTA below.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: optional poster image; cell 2: the video link (YouTube, Vimeo, videomarketingplatform.co .thtml, Dynamic Media /is/content/ or .mp4) plus optional heading, text/quote and a CTA link (a link alone in its paragraph). The video link text becomes the play button / player accessible label.
