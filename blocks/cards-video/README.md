# cards-video

Custom **cards** block. Purpose: Row of video cards: poster image with a play button that loads the video inline.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: poster image; cell 2: optional heading/text plus the video link (YouTube, Vimeo, Dynamic Media /is/content/ or .mp4). The link text becomes the play button accessible label.

## Supported variations

No variations.
